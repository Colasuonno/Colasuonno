# 👋 Giovanni Colasuonno

🎓 BSc in Computer Science — **Sapienza Università di Roma**
📚 MSc in Computer Science (ongoing) — **Sapienza Università di Roma**

Backend and embedded developer. I work mainly on ERP customization, Kubernetes-based
deployments and microcontroller firmware, with a side interest in CAD and additive manufacturing.

---

## 🔧 Focus areas

**🧩 ERP / Backend**
Custom Odoo modules: ORM models, business logic, QWeb reports, REST/XML-RPC integrations
and data migration between major versions. PostgreSQL, Python.

**☸️ Cloud native & GitOps**
Kubernetes workloads managed declaratively with ArgoCD — Git as the single source of truth,
automated sync and rollback. Containerization with Docker, CI/CD pipelines for build, test
and deployment.

**⚡ Embedded systems**
Firmware for ESP32 / ESP8266 in C/C++ (`Arduino.h`, ESP-IDF toolchain): sensor interfacing
over I²C/SPI/UART, Wi-Fi and MQTT connectivity, OTA updates, low-power modes.

**📱 Android**
Native applications in Java/Kotlin — lifecycle management, background services,
REST clients and local persistence.

**🖨️ CAD & 3D printing**
Parametric modelling and FDM printing, mostly enclosures and mechanical parts for
the embedded projects above. Design, slicing, tolerancing, iteration.

**🕹️ Previously**
Minecraft server plugins (Java, Bukkit/Spigot API) — event-driven systems, custom
game mechanics and admin tooling. No longer maintained, but where I started.
